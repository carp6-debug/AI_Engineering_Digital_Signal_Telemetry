# 🛠️ Step‑by‑Step Agentic Loop

## **1. Load Chroma**
```
import chromadb
client = chromadb.Client()
collection = client.get_collection("radio_cases")
```

## **2. Load your finetuned model**
```
from transformers import AutoModelForCausalLM, AutoTokenizer

model_path = "./finetuned_model"
model = AutoModelForCausalLM.from_pretrained(model_path)
tokenizer = AutoTokenizer.from_pretrained(model_path)
```

## **3. Define the agent function**
```
def troubleshoot(question):
    # Step 1 — RAG retrieval
    results = collection.query(query_texts=[question], n_results=3)
    retrieved = "\n\n".join(results["documents"][0])

    # Step 2 — Build agent prompt
    prompt = f"""
User Question:
{question}

Relevant Cases:
{retrieved}

Task:
Analyze the question using the retrieved cases.
Provide:
- RootCause
- ResolutionSteps
- Notes
"""

    # Step 3 — Model inference
    inputs = tokenizer(prompt, return_tensors="pt")
    output = model.generate(**inputs, max_new_tokens=300)
    return tokenizer.decode(output[0], skip_special_tokens=True)
```

## **4. Use the agent**
```
answer = troubleshoot("Why does my P25 radio show INVALID NAC?")
print(answer)
```
